Get started in a minute

  1. Open Audit Trail > Configuration > Audit Rules and create a rule for a model, e.g. Contacts.
  2. Choose the operations and fields to log, and optionally alert recipients and ignored users.
  3. Click Add 'Audit History' to Action Menu to open a record's history straight from the record.
  4. Review changes under Audit Logs (click View Diff or Restore on any row), see trends in Reporting > Summary, and export from Reporting > Export.
